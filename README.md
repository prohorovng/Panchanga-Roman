# Panchanga Roman

Персональная панчанга Романа на 3 октября 2026 года, Брашов, Румыния.

Адаптивный сайт на русском языке: временные окна, пять элементов ведического календаря, личные показатели и полный исходный текст.

## Возможности

- Фильтрация временных окон.
- Раскрывающиеся пояснения.
- Экспорт выбранного окна в календарь (`.ics`), время Брашова UTC+3.
- Сохранение страницы в PDF через печать браузера.
- Работа на телефоне и компьютере без внешних библиотек.

## Открытие

Откройте `index.html` в браузере. Установка и сборка не требуются.
Для доступа по ссылке разместите файл на статическом HTTPS-хостинге.

Расчёты и интерпретации перенесены из предоставленного текста. Страница не выполняет новые расчёты и относится к фиксированной дате 3 октября 2026 года.
